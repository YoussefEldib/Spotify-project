# Spotify-project
Spotify analytics and creating interactive meaningful dashboard # Spotify Data Analysis 🎵

This project analyzes Spotify data to discover insights about artists, genres, followers, popularity, and music trends.

### 🛠️ Tools

* Excel
* Power Query
* Power BI
* DAX

### 📊 Analysis

The project includes:

* Top Artists
* Popular Genres
* Artist Followers
* Popularity Analysis
* Interactive Power BI Dashboard

### 📁 Dataset

The dataset was obtained from Kaggle and used for educational purposes.

### 🎯 Goal

To practice data cleaning, analysis, visualization, and dashboard development using Power BI.
